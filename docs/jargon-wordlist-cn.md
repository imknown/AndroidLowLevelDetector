# 黑话词表:浮夸词 → 大白话

写文档、写汇报时的自查对照表:第一列是类别,第二列是中文浮夸词,第三列是对应的英文说法,第四列是口语大白话解释。遇到旧文档或外部文章里的这些词,按第四列理解;自己写文档时,按第四列的说法写。

规则提醒:本仓库文档里,标题行文字不动(保锚点)、代码块不动;其余地方见到这些词,按解释改写。JOTTINGS.md 是手写笔记,不受此表约束。另外,「英文难词」类收的是四六级往上的普通英文单词(如 verdict、stale),查生词时到那一类按第三列找;最后一列大白话均按「字面义 + 项目语境义」双写。
