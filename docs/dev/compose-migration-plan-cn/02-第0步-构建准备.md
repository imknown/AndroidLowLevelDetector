## 目标

Compose 侧唯一缺的依赖: `lifecycle-runtime-compose` (提供 `collectAsStateWithLifecycle()`). 其余 Compose 环境 (编译器插件, BOM, 主题三件套) 都已在本分支就绪, 本步顺便把"每样东西是干嘛的"过一遍.

## 改动

`gradle/toml/android.toml` — 已有 `lifecycle` 版本号 (2.11.0), 只需加一条库, 并入 compose bundle:

```diff
 lifecycle-runtime = { group = "androidx.lifecycle", name = "lifecycle-runtime", version.ref = "lifecycle" }
+lifecycle-runtime-compose = { group = "androidx.lifecycle", name = "lifecycle-runtime-compose", version.ref = "lifecycle" }
 lifecycle-viewmodel = { group = "androidx.lifecycle", name = "lifecycle-viewmodel", version.ref = "lifecycle" }
```

```diff
-compose = ["compose-ui", "compose-ui-graphics", "compose-ui-tooling-preview", "compose-material3", "activity-compose", "lifecycle-viewmodel-compose", "navigation3-runtime", "navigation3-ui", "lifecycle-viewmodel-navigation3"]
+compose = ["compose-ui", "compose-ui-graphics", "compose-ui-tooling-preview", "compose-material3", "activity-compose", "lifecycle-runtime-compose", "lifecycle-viewmodel-compose", "navigation3-runtime", "navigation3-ui", "lifecycle-viewmodel-navigation3"]
```

无需改 `app/build.gradle.kts` — 它引用的是整个 `compose` bundle, 由 `build-logic` 的 `AndroidApplicationComposeConventionPlugin` (`Compose.kt`) 统一施加 BOM 平台.

## 为什么是它, 为什么只有它

现有 compose bundle 成员盘点 (Compose 系工件由 BOM 2026.09.00 管版本; **Navigation 3 与 lifecycle-viewmodel-navigation3 不在 Compose BOM 映射内**, 由版本目录的 `navigation` / `lifecycle` 版本号显式指定):

| 依赖 | 作用 | 本计划哪步用 |
| --- | --- | --- |
| `compose-ui` / `compose-ui-graphics` | Compose 基础运行时与图形 | 全程 |
| `compose-material3` | Material 3 组件与主题 | 第 1 步起 |
| `compose-ui-tooling-preview` | `@Preview` 注解与渲染 | 第 1 步起 |
| `compose-ui-tooling` (debugImplementation, 已在 `Compose.kt`) | IDE 预览/布局检查器 | 开发期 |
| `activity-compose` | `ComponentActivity.setContent { }` | 第 2 步起 |
| `lifecycle-viewmodel-compose` | 在组合里 `viewModel()` 拿 ViewModel | 第 2 步起 |
| `navigation3-runtime` / `navigation3-ui` / `lifecycle-viewmodel-navigation3` | Navigation 3 与返回栈级 ViewModel 作用域 | 第 6 步 |
| **`lifecycle-runtime-compose` (本步新增)** | **`collectAsStateWithLifecycle()`** | **第 2 步起** |

刻意**不**新增的:

- **任何 Style API 依赖**: 最新的样式 API(`Style` / `Modifier.styleable`, 见第 1 步 3.4 节) 就在 `compose-ui`/`foundation` 里 (foundation 1.11 起引入, 实验性), BOM 已覆盖;

- **Material Icons**: 四个标签页图标是现成的矢量资源 (`ic_home_24dp.xml` 等), Compose 用 `Icon(painterResource(R.drawable.ic_home_24dp), null)` 直接复用, 不引图标库;
- **material3-adaptive**(`NavigationSuiteScaffold`): 适合"手机底栏/平板侧栏自适应"的 app. 本项目现状是固定底部导航, 先用 `NavigationBar` 等价替换 (最小改动), 自适应留作后续独立需求;
- **Compose 版 ConstraintLayout**: 现有 XML 约束都极简, Column/Row/Box 足够.
