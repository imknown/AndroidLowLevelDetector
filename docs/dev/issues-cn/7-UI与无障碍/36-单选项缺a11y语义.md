# 36 设置页单选项缺 selectable 与选中态语义

> 返回 [README 索引](../README.md) · [7 · UI 与无障碍](../README.md#7--ui-与无障碍).

**严重程度: P2 | 修复难度: 低**

**结论**: 选项对话框 `SettingsChoiceDialog()` 里, 每个单选项是一个 `Row(modifier = Modifier.fillMaxWidth().clickable { onSelect(value) }.padding(vertical = 12.dp))`, 尾部放 `RadioButton(selected = value == selected, onClick = null)` — 纯展示, 点击由行处理. 行上既没有 `Modifier.selectable`, 也没有 `Role.RadioButton`, 更没有选中态语义: 焦点落在这一行时, 无障碍节点只说它可点击, 说不出 "这一项已选中".

代码侧可核实的是行的 modifier 只有 `clickable` (`grep` 全仓: `selectable` 零出现, `Role.RadioButton` 零出现), 以及 `RadioButton` 的 `onClick = null`. 读屏实际念出什么词句需要真机 + TalkBack 核对, 本条不下断言.

**开关行不在本条范围内**: `SettingsSwitchRow()` 今天已经是修复方向要给的形状 — 行走 `.semantics(mergeDescendants = true) {}` + `.toggleable(value = checked, role = Role.Switch) { onCheckedChange(it) }`, 尾部 `Switch(checked = checked, onCheckedChange = null)` 降为纯展示, 注释写明 "toggleable, not clickable: it carries the checked state for TalkBack". 单选行照这个模式补齐即可.

**修复方向**: `SettingsChoiceDialog()` 的选项行把 `clickable { onSelect(value) }` 换成

```kotlin
Row(
    modifier = Modifier
        .fillMaxWidth()
        .semantics(mergeDescendants = true) {}                    // 标题与选中态作为一个焦点读出
        .selectable(selected = value == selected, role = Role.RadioButton) { onSelect(value) }
        .padding(vertical = 12.dp),
) {
    RadioButton(selected = value == selected, onClick = null)     // 仍为纯展示
    Text(text = label, modifier = Modifier.padding(start = 12.dp))
}
```

`selectable` 自己写入选中态语义 (与开关行的 `toggleable` 对应), `Role.RadioButton` 报出控件角色.
