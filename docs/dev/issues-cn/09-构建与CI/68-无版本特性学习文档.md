**严重程度: P3 | 修复难度: 中**

**需求**: 开设一系列专门文档作为学习记忆, 按版本记录新特性: Kotlin 各版本新特性, Android 系统新特性 API, AndroidX 新特性 API, 第三方库最新 API 等.

该系列记约定背后的版本特性依据. 归属暂放 09 (版本与工具链邻域), 不合适再挪.
