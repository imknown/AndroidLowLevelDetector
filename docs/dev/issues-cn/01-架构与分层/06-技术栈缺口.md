# 06 技术栈缺口

> 返回 [README 索引](../README.md) · [1 · 架构与分层](../README.md#1--架构与分层).

**严重程度: P1(🟡, 工程配套) | 补齐节奏: 大重构开工前先补齐测试基础设施, 其余分批**

**已就位** (在 `gradle/toml/` 与 `build-logic/` 可核): coroutines (`kotlinx-coroutines-android`),  
Ktor + OkHttp 引擎  
(`ktor-client-okhttp`), kotlinx.serialization, libsu, Compose (BOM + Material 3),  
LeakCanary (`debugImplementation`),  
StrictMode (`app/src/debug/.../MyDebugApplication.kt` 的 `StrictMode.enableDefaults()`),  
JUnit 4 (本机单测与仪器测试), MockK (交互验证), Robolectric (本机单测的 Android 框架模拟).  
设置页是手写 M3,  
`androidx.preference` 已不在依赖目录里, View 时代的偏好界面没有留下兼容层.

**缺** (以下依赖或工具链在版本目录与 `build-logic` 里零出现): DataStore (+protobuf), Baseline Profiles,  
App Startup,  
Macrobenchmark, Turbine, Espresso, Compose UI 测试. 测试基础设施的现状:  
`build-logic/.../KotlinAndroid.kt` 的 `configureTest()` 给 `test` bundle 挂 `junit`,  
给 `androidTest` bundle 挂 `test-core`, `test-ext-junit` 与 `test-runner`;  
本机单测的 JUnit 4 由版本目录给, 仪器测试那一路的 JUnit 4 由 `androidx.test.ext:junit` 与  
`androidx.test:runner` 传递带入.  
`base/src/test/.../DateTimeExtTest.kt` 有 4 个真实测试方法 (`isLldDatetime()` 的格式契约与 locale 无关性),  
`app/src/test/.../ui/base/list/MyModelTest.kt` 有 3 个 (`MyModel.key` 的映射与默认值),  
`app/src/androidTest/.../snapshot/ModelSnapshotTest.kt` 是三页行数据的快照生成器 (一次性的, 不进 CI).  
`app/src/test` 与 `base/src/test` 合计 26 个测试类, 116 个测试方法 (app 25 类 112 方法, base 1 类 4 方法),  
其中包含上面两份契约测试; CI 上的检查已随  
[#50](../archived/09-构建与CI/50-CI只编译不测试.md) 上线, 缺的是覆盖广度与下面这些工具链.

**版本 pin**: 唯一进入依赖解析的非稳定 pin 是 `kotlinx-serialization` (`gradle/toml/kotlin.toml`);  
[09-构建约定](../../../agents-cn/09-构建约定.md) 的版本分级允许 RC 直接进生产, 所以它不违规,  
只是要如实记录的那一个 pin. `isPreview = "false"`, 因此走的是  
`compileSdk` / `targetSdk` / `buildTools` 的稳定条目; `compileSdkPreview`,  
`targetSdkPreview` 与 `androidGradlePlugin-canary` 这些条目当前没有消费者  
(挂在 toml 里没人用的条目归 [#55](../09-构建与CI/55-构建配置杂项.md)).

**不算缺口**: Coil 没有引入: 全项目唯一的图片用法是 `painterResource(tab.iconRes)` 加载本地导航图标 (`AppRoot()`),  
没有任何网络图片需要加载器.  
五个拆分版本目录 (`gradle/toml/` 下 build/android/kotlin/google/thirdParty) 是 [09-构建约定](../../../agents-cn/09-构建约定.md) 记的项目约定, 不算问题.

**补齐节奏**: JUnit 4 与 MockK 已就位; Turbine 随首个 Flow 测试进 (大重构开工前);  
Espresso / Compose UI 测试随迁移完成后的测试立项补齐 (迁移本身不带测试);  
Baseline Profiles / App Startup / Macrobenchmark 排在更后面.  
Robolectric 现用 4.17, 升级归下一个独立单元 (桥接包已删, 卡点解除).
