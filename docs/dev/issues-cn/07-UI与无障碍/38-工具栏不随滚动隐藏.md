# 38 工具栏与底栏不随滚动移出屏幕

> 返回 [README 索引](../README.md) · [7 · UI 与无障碍](../README.md#7--ui-与无障碍).

**严重程度: P2(🟡) | 修复难度: 中**

- **代码事实**: `AppRootShell()` 的 `Scaffold` 里 `topBar = { TopAppBar(...) }` 没有传 `scrollBehavior`, `bottomBar = { NavigationBar { ... } }` 同样固定. 源码 grep `scrollBehavior` / `layout_scrollFlags` / `hide_bottom_view_on_scroll_behavior` 零命中 — 两个栏今天都不随滚动收起, 栏因此常驻占高, 小屏上少一屏内容; 栏既然不移动, 也就没有 "可中断的退出动画" 可言.
- **滚动容器侧同样没有接线**: 两个 `LazyColumn` 的 `listState` (`ui/base/list/MyModelListScreen.kt` 的 `MyModelListContent()`, `ui/settings/SettingsScreen.kt` 的 `SettingsContent()`) 现在只有一个消费者 — 自绘滚动条 `.nonInteractiveScrollbar(listState, ...)` (见 [#37](37-滚动条可拖动是stub.md)); 没有一处 `nestedScroll`. 实现时 `scrollBehavior` 要在 `AppRootShell()` 与页面之间来回传一次, 这是本条工作量所在.
- **历史对照 (证据, 不是现状)**: 原 `ui/res/layout/main_activity.xml` (已随 `64e36091` 删除) 的 `AppBarLayout` **没有** `layout_scrollFlags`, 只有 `BottomNavigationView` 挂了 `app:layout_behavior="@string/hide_bottom_view_on_scroll_behavior"` — View 时代只隐藏底栏, 工具栏固定. 迁到 Compose 后连底栏那一半也没有延续, 所以缺口比当年估计的大: 两侧都得重做.
- **需求出处已不在仓库**: 这条原本拿产品规格文档当依据, 那份规格已删除, 所以 "工具栏随滚动收起" 现在没有书面需求. 它不是回归 — View 时代也只做了一半. **是否仍要做, 归负责人定**; 确认要做之后再动代码.
- **动手前须知**: M3 的 `TopAppBarDefaults.*ScrollBehavior` 与配套的 `Modifier.nestedScroll` 仍属 `@ExperimentalMaterial3Api`, 而 [AGENTS.md](../../../../AGENTS.md) 规定新实验 opt-in 要先向负责人报告再采纳 (`AppRootShell()` 已经为 `TopAppBar` 本身带 `@OptIn(ExperimentalMaterial3Api::class)`, 其注释写明 material3 1.4.0 里它仍实验; 版本 pin 在 `gradle/toml/android.toml` 的 `compose-bom = "2026.09.00"`). 底栏那一半另需核实当前 material3 给 `NavigationBar` 提供了什么位移手段 — 本仓库没有任何与旧 `hide_bottom_view_on_scroll_behavior` 等价的现成开关.
