# 48 命名漂移

> 返回 [README 索引](../README.md) · [8 · 反模式与卫生](../README.md#8--反模式与卫生).

**严重程度: P2(🟢) | 修复难度: 低**

本条原先是 "代码用词 对 规格用词" 的对照结果; 对照的另一方 (规格文档) 已不在仓里, 所以现在能核对的只有现状本身, 涉及设置页两处标题:

- 分组标题 `ui/settings/res/values/strings.xml → interface_title` = "Interface" (zh-rCN / zh-rTW "界面", fr-rFR "Interface"). `SettingsScreen` 里 `SettingsCategoryHeader(R.string.interface_title)` 之下只有两行 — `interface_themes_title` ("Themes") 与 `interface_scroll_bar_title` ("Scroll bar mode"); 功能开关与关于区各自另有 `function_title`, `about_title` 分组.
- 许可行标题 `ui/settings/res/values/strings.xml → about_licenses_title` = "License" (zh-rCN "协议", zh-rTW "協議", fr-rFR "Licences"), 而同一条列表项的说明 `about_licenses_summary` 写的是 "Referenced open-source repositories", 落点 `about_licenses_uri` 是仓库里的 `gradle/toml` 目录 — 标题说许可, 说明与落点说的是被引用的开源库.

没有文档钉住这两个标题该叫什么, 也就没有 "代码偏离规格" 这条可判的差; 措辞改不改, 以及改成什么, 由负责人定.

现状是有意接受, 无待办: strings 由人工撰写并人工翻译, 标题不做批量改动. 许可行的落点合不合格是另一件事, 见 [#56](../10-权限与合规/56-License行不合规.md).
