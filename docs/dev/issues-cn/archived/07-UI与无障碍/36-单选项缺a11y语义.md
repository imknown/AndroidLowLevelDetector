# 36 设置页单选项缺 selectable 与选中态语义

> 返回 [README 索引](../../README.md) · [7 · UI 与无障碍](../../README.md#7--ui-与无障碍).

**严重程度: P2 | 修复难度: 低 | 状态: 已修复 (代码形状照官方 radio-group 模式改齐; 真机 TalkBack 朗读未核)**


**现象**: 选项对话框 `SettingsChoiceDialog()` 里,  
每个单选项是一个 `Row(modifier = Modifier.fillMaxWidth().clickable { onSelect(value) }.padding(vertical = 12.dp))`,  
尾部放 `RadioButton(selected = value == selected, onClick = null)`, 纯展示,  
点击由行处理. 行上既没有 `Modifier.selectable`,  
也没有 `Role.RadioButton`, 更没有选中态语义: 焦点落在这一行时, 无障碍节点只说它可点击, 说不出 "这一项已选中".

**代码侧可核实的是行的 modifier 只有 `clickable` (`grep` 全仓: `selectable` 零出现, `Role.RadioButton` 零出现),  
以及 `RadioButton` 的 `onClick = null`. 读屏实际念出什么词句需要真机 + TalkBack 核对, 本条不下断言.**

**开关行不在本条范围内**: `SettingsSwitchRow()` 今天已经是修复方向要给的形状:  
行走 `.semantics(mergeDescendants = true) {}` +  
`.toggleable(value = checked, role = Role.Switch) { onCheckedChange(it) }`,  
尾部 `Switch(checked = checked, onCheckedChange = null)` 降为纯展示, 注释写明 "toggleable, not clickable:  
it carries the checked state for TalkBack". 单选行照这个模式补齐即可.

**怎么修的**: 单选行照开关行模式补齐: 行走 `.semantics(mergeDescendants = true) {}` +  
`.selectable(selected = value == selected, role = Role.RadioButton) { onSelect(value) }`,  
padding 保持在 `selectable` 之后 (ripple 覆盖整行), `RadioButton` 保持 `onClick = null` 纯展示,  
点击行为与视觉零变化. 另按负责人的决定在选项 `Column` 上加了条目原方案没有的  
`Modifier.selectableGroup()` (官方 radio-group 配套 API, 一行改动):  
读屏会把整组播报成 "组内第几项" 的序号信息. `clickable` 因其余行仍在用而保留导入.
