# R11 "License"行链接到 version catalog

> 返回 [README 索引](../README.md) · [组3 · 暂缓](../README.md#组3--暂缓-原因见危害列标注).


**严重程度: P2(🟢)**

该行打开 GitHub 上的 `gradle/toml`(`ui/settings/res/values/strings.xml → licenses 行`, 复验) 而非应用内开源许可页. 多数开源许可要求许可文本让人能方便看到, 只有一个 toml 链接算不上合格, 与 "开源许可" 的条目名不符.
