## 3. getStringProperty 的版本门控散落在调用方

`getStringProperty()` 的 `condition: Boolean = true` 参数, 把 "该属性最低哪个 Android 版本才有" 的知识压给每个调用方 (`HomeRepository` 里出现了 10 余处 `isAtLeastAndroid9()` 之类实参). 版本门槛应与 key 定义放在一起:

```kotlin
// core/property/PropKey.kt — 定义处自带版本信息
data class PropKey(val key: String, val since: Int? = null)

// 调用方不再记得门槛
val PROP_RO_VENDOR_SECURITY_PATCH = PropKey("ro.vendor.build.security_patch", Build.VERSION_CODES.P)
```

## 5. PropRepository.getBuildProp 的字符串套娃解析

`PropRepository.getBuildProp()` 对 `getprop` 输出做 `[key]: [value]` 字符串往返解析. 属于 "把终端展示格式当数据格式" 的 stringly-typed(用字符串代替结构化数据) 味道. 低优先级: 等 AR-01 做完, 可在 DataSource 层直接产出 `Pair<String, String>`.

## 6. ShellDefault 零调用 (保留为原生备选)

`base/src/main/java/.../shell/impl/ShellDefault.kt` 定义后全项目无引用 (实际使用的是 `ShellLibSu`). 当时的判断是直接删除.

**处置 (2026-09-12 负责人定, 2026-09-22 补充理由)**: 保留不删 — 它是**不依赖 libsu 的原生实现**, 作为 `ShellLibSu` 的备选留在仓里;"当前无人调用" 只是现状, 未来是否需要尚未确定, 所以不作为欠账计入.

## 7. LldManager 的属性名带动词后缀

`LldManager.savedLldJsonFileOrThrow`: `val savedLldJsonFileOrThrow by lazy { ... }` — 属性命名带 `OrThrow` (方法后缀习惯), 读起来像在调用函数. 改造为 `LldFileStore` (AR-04) 时顺手改为 `val savedJsonFile: File`.

## 8. 版本 / 日期字符串按字典序比较

四处用 `>=` / `<` 直接比较字符串, 正确性完全依赖格式恒定 (`HomeRepository.detectSecurityPatch()` 安全补丁, `detectMainline() 里的 versionName >= latestGooglePlaySystemUpdates` Mainline, `detectVndk() 里的 vndkVersionResult >=` VNDK, `LldManager.copyJsonIfNeededOrThrow()` lld 版本). 零填充的 ISO 日期目前碰巧正确, 但位数一变 (如 `9` 对 `10`) 即静默出错:

```kotlin
mySecurityPatch >= lldSecurityPatch      // "2026-08-05" 字典序比较, 目前靠零填充保平安
savedLldVersion < assetLldVersion        // "2026-09-02 20:55 +0800" 同上
```

版本号统一走 `Version(...)` 比较, 安全补丁解析为 `LocalDate` / `YearMonth` 后比较.

## 9. 标题在组合期解析, 详情在检测期冻结

`MyModelCard` 的标题走 `stringResource(id)` 现解析 (`MyModelCard.kt 里的 MyModelTitle() 组合函数`, 经 `MyModelTitle() 里` 那个 sealed 解析 helper), `detail` 却是检测时冻结好的字符串 (`MyModelCard() 里排版 detail 的那段` 直接排版): 系统切换语言后, 同一行会显示 "新语言标题 + 旧语言详情", 直到手动刷新. View 时代这件事发生在 `MyAdapter.onBindViewHolder` (每次绑定调 `MyApplication.getMyString(title.id)`), 载体换成了 Composable, 缺陷原样搬了过来.[AR-01](../组2-主线重构/14-AR-01-无领域模型.md) 的 mapper 落地之后, 标题与详情统一在数据到位时解析一次, 卡片只读现成字符串.

## 10. Easter egg 计数器放在 ViewModel

`SettingsViewModel.timesLeft` (`SettingsViewModel.timesLeft`) 是可变字段 + 返回资源 ID 的查询函数 — "连点 7 次版本号" 的交互细节属于界面层. 挪进 `SettingsScreen` (一个 `remember` 计数器即可), 或改为不可变状态流转.
