## 核心结论

1. AGP 9.5.2 存在: 2026-11-20 随 Android Studio Rabbit 2 Patch 2 发布, 修两个 issue, 其中一条是 Isolated Projects 下带工程间依赖的 app 构建失败.  
   核实程度: **已验证** (官方公告与 closed issues 页, 见 [01](01-agp-9-5-2.md)).
1. 仓库的 AGP 落在 9.5 线最新 patch 上, 这个版本没有查到的官方已知问题.  
   核实程度: **已验证** (修复清单与发布页, 见 [01](01-agp-9-5-2.md)).
1. Gradle 10.0 还没有发布: 发布表最新到 9.9.1, 当前版本接口返回 9.9.1, RC 接口返回空对象, 没有任何 10.x 构件.  
   核实程度: **已验证** (见 [02](02-gradle-版本线.md)).
1. Gradle 9 线最新 patch 是 9.9.2, 2026-11-19 构建, 修四个高危安全问题, 并把 9.9.0 公布的两条已知问题一起清掉; 官方直接建议升到这一版.  
   核实程度: **已验证** (release notes 与 `./gradlew --version` 的 Build time, 见 [02](02-gradle-版本线.md)).
1. 仓库的 wrapper 指向 9.9 线的第二个 patch, 也就是上面那一版, sha256 与上游文件逐字一致.  
   核实程度: **已验证** (见 [04](04-仓库核对.md)).
1. Java 25 从 Gradle 9.1.0 起既支持 daemon 也支持工具链, 上限到 JVM 27; 仓库的 daemon 与代码工具链都在这条边界内.  
   核实程度: **已验证** (兼容矩阵与 `--version` 输出, 见 [03](03-gradle-兼容要求.md)).
1. 配置缓存自 Gradle 9.0 起是首选执行方式, 官方写明将在 Gradle 10 默认开启; 仓库已经开着它, 两次成功构建都写进了缓存条目, 10.0 到来时不多出切换点.  
   核实程度: **已验证** (配置缓存文档加构建实测, 见 [04](04-仓库核对.md)).
1. 整套组合实测跑通: 配置阶段与 Foss debug 的 Kotlin 编译都成功, 四个 ABI 的 CMake 都构建, 日志里没有弃用条目, 只有 incubating 提示与一条 experimental 警告.  
   核实程度: **已验证** (`./gradlew help` 与 `./gradlew :app:compileFossDebugKotlin` 的输出, 见 [04](04-仓库核对.md)).
1. 头两次构建失败是 agent 的 shell 没继承到 Git 的 PATH, 与两个版本都无关; 用户自己的终端与 Android Studio 里 Git 正常.  
   核实程度: **已验证** (同一条命令在两个 shell 里结果不同, 见 [04](04-仓库核对.md)).
1. 三处组合超出官方覆盖范围: AGP 9.5 配 Gradle 9.9 (Gradle 只测到 9.5.0-alpha10), KGP 用 2.5 的 RC (Kotlin 官方表最高 2.4.21), compileSdk 取在 37 的子版本上.  
   核实程度: **已验证** (实测能跑) 加 **不确定** (官方页只写它测过哪些, 不判这些组合以后会怎样).
1. 现在没有要适配的: AGP 9.1 到 9.5, Gradle 9.0 到 9.9 这两条已发布线内, 仓库零待改项, 全量 debug 构建在 `warning.mode=all` 下零弃用.  
   核实程度: **已验证** (全量构建输出加全仓 grep, 见 [05](05-适配判定.md)).
1. 往前看只有一处必改: AGP 10.0 移除急切属性写入, 仓库命中一处 `buildConfigField()`; 另有两处要盯着, 第三方插件版本与 `configureondemand` 去留.  
   核实程度: **已验证** (官方移除清单对照) 加 **不确定** (10.0 还没发布, 没有实际警告可核).
1. 9.x 线内另有八处可选项, 不是兼容要求: 三项建议做 (release 补 R8 规则校验, 处理 `compileSdkExtension` 这个死配置, git 取值兜底), 三项可做可不做, 两项先别动.  
   核实程度: **已验证** (官方发布说明加本仓库构建与 grep, 见 [06](06-可选改进.md)).
