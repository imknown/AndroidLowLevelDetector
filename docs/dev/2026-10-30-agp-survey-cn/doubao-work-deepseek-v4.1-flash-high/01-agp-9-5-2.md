# AGP 9.5.1 与 9.5.2: 发布日期, 修复清单, 兼容要求与已知问题

> **状态**: **frozen**. 写下的结论不改; 后来的更正留在原处.  
> 仓库核对在 [04](04-仓库核对.md).

数据基准日: 2026-11-25. 版本存在性与发布日以官方公告, closed issues 页与 release notes 页为准.  
下面凡是"已验证"的条目, 都是当次抓页面读到原文的; "不确定"的条目写清查不到的到底是什么.

## 版本与发布日期

| 版本 | 发布日 | 同发的 Studio | 内容 |
|---|---|---|---|
| 9.5.0 | 2026-11-05 | Rabbit 2 | 9.5 线首版 |
| 9.5.1 | 2026-11-05 | Rabbit 2 Patch 1 | 小修复, closed issues 页没有列 AGP 的 issue |
| 9.5.2 | 2026-11-20 | Rabbit 2 Patch 2 | 修两个 issue |

9.5.1 与 9.5.2 的存在, 由 Rabbit 2 Patch 1 与 Patch 2 的公告核实: 两篇都写 "Released together with: Android Gradle Plugin 9.5.x".  
核实程度: **已验证**.

9.5.0 的发布日只有一个来源: developer.android.com 的 latest updates 页写 "Android Gradle Plugin 9.5.0, November 5, 2026".  
同一天它还把 Rabbit 2 Patch 1 标成 Stable, 说明这一页的日期至少是 Patch 1 之后更新过的.  
核实程度: **不确定** (发布说明页本身只写 "October 2026", 没有具体日).

## 9.5.2 修的两个 issue

| issue | 内容 |
|---|---|
| #581925548 | 多个嵌套 jar 的 fat aar 自 9.5 起合并 Java 资源失败 |
| #582417470 | 在 Isolated Projects 下, 带 `implementation(project(...))` 的 Android app 即将构建失败 |

出处: Rabbit 2 Patch 2 的官方公告 (页头日期 2026 年 11 月 20 日, 星期五) 与 Rabbit 2 的 closed issues 页的 Patch 2 小节, 两处列的是同两条.  
核实程度: **已验证**.

第二条值得单独看: 官方把带工程间依赖的 app 在 Isolated Projects 下的失败当成回归修掉了.  
这条修复说明 9.5 线出现过这个写法的问题, 9.5.2 之后才干净. 仓库有没有命中这个写法, 见 [04](04-仓库核对.md).

## 9.5.1

Patch 1 的公告原文只有一句 "This release includes minor fixes and improvements", closed issues 页的 Patch 1 小节也没有列 AGP 的 issue.  
所以这一版修了什么, 官方没有公开. 核实程度: **已验证** (两页都没有修复条目).

## 9.5 的兼容要求

摘自 AGP 9.5.0 发布说明页的 Compatibility 节:

| 项 | 最低 | 默认 |
|---|---|---|
| Gradle | 9.6.0 | 9.6.0 |
| SDK Build Tools | 36.0.0 | 36.0.0 |
| NDK | 不适用 | 28.2.13676358 |
| JDK | 17 | 17 |

同一节还有一句 "The maximum API level that Android Gradle plugin 9.5 supports is API level 37".  
全节没有 37.1 或 37.2 的行, 也没有说子版本怎么算.  
核实程度: **已验证** (这一节的原文) 加 **不确定** (子版本的支持范围).

## 已知问题

- 9.5.0 的发布说明页只有 Compatibility, Automated backup and restore testing, Fixed issues 三节, 没有 Known issues 一节.
- Patch 1 与 Patch 2 的公告只列修复项, 不列已知问题.
- 9.5.0 页里 "9.5.1" 小节写 "No public issues were marked as fixed in AGP 9.5.1", 也就是说公认的 issue 追踪里这一版没有修复记录.

查不到 9.5.2 专属的已知问题清单. 核实程度: **不确定** (官方没有单独的已知问题页可核对, 只能说这些页面上没有).

## 9.6 线的现状 (顺带核到)

- 9.6.0 发布说明页的 Compatibility 节写 Gradle 最低与默认都是 9.8.2, 页尾写 "Last updated 2026-11-18".
- 页内 Fix issues 只到 9.6.0-alpha03, 没有 9.6.0 稳定版自己的小节.
- 仓库的 `androidGradlePlugin-canary` 指向 9.6 线的 alpha, 编号比页面上列出的 alpha03 更新.

核实程度: **已验证** (页面原文) 加 **不确定** (9.6.0 稳定版发没发, 页面状态看不出来).
