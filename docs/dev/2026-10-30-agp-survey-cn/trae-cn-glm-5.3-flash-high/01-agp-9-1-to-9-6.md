## AGP 9.1

- 状态: 稳定, 最新 9.1.1.
- R8 默认在编译到 DEX 时把类重打包进无名 (默认) 包, 等效隐式加了 `-repackageclasses`;  
  想退回旧行为用新规则 `-dontrepackage`.
- 破坏性: 靠包名做反射或 ServiceLoader 类查找的场景受重打包影响.
- `-maximumremovedandroidloglevel` 支持具名日志级别  
  (ASSERT/ERROR/WARN/INFO/DEBUG/VERBOSE/NONE, 须全大写).

## AGP 9.2

- 状态: 稳定, 最新 9.2.1. 9.2.1 修复升级 9.2.0 后的  
  `ClassNotFoundException: com.android.tools.r8.RecordTag` (issue 504996348).
- 统一测试与覆盖率报告 (实验性): `gradle.properties` 设  
  `android.experimental.reportAggregationSupport=true`, 生成合并 unit 与 instrumentation  
  结果及覆盖率的 HTML 总览.
- R8 收紧 `-keepattributes` 通配符: 它不再匹配 `RuntimeInvisibleAnnotations`,  
  `RuntimeInvisibleParameterAnnotations`, `RuntimeInvisibleTypeAnnotations`;  
  要保留这三类必须显式写全名. 对依赖反射读注解的库有实际影响.
- R8 keep 规则的成员名支持取反模式, 例如 `*** !*ForTesting(...);`, `-if` 前置条件里同样可用.
- 内置 KGP 依赖升到 2.3.10, 细节在 [02](02-agp-compatibility-kgp.md).

## AGP 9.3

- 状态: 稳定, 最新 9.3.2. 9.3.2 修复 JDK 17 上 lint 的崩溃  
  (`NoSuchMethodError: java.util.List.removeLast()`, issue 522845800).
- 新增独立任务 `analyzeReleaseR8Config` (例如 `./gradlew :app:analyzeReleaseR8Config`),  
  不走完整 APK/Bundle 流水线直接出 keep 规则优化报告.
- build type 里新增 `optimization` DSL: 开启后同时启用代码优化与优化版资源收缩,  
  且不再需要手动指定默认 Android keep 规则文件; 旧 DSL 继续支持.  
  9.5.0-alpha06 修过它不回写 `isMinifyEnabled` 的坑 (issue 556343682).
- keep 规则源集: 规则文件放 `src/<variant>/keepRules/`, 后缀 `.keep`;  
  app 模块, library 模块与 KMP consumer 规则都支持.
- 这三项都是增量选项, 旧 DSL 不移除, 无强制迁移.

## AGP 9.4

- 状态: 稳定 9.4.0. 一个 caveat: 两站抓到的 9.4 release notes 的 Fixed issues  
  都只列到 9.4.0-alpha04, 没有稳定版小节; 9.4.1 的存在只有间接证据  
  (9.5.0-alpha09 的修复条目标题里提到 "AGP 9.4.1").
- Variant API 模块级退避: AGP 10 起新 Variant API 强制所有项目使用;  
  9.4 起可在 `gradle.properties` 写 `android.newDsl.optOut=:example-lib1` 按模块临时退出.  
  这个开关是过渡辅助, 随 `android.newDsl` 一起在 AGP 10.0 移除.
- 动态 feature 与 app 模块的 flavor dimension 严格 1:1 校验: 9.4 起默认以警告报告  
  缺失, 多余或不匹配的 dimension; 设 `android.enforceDynamicFeatureVariantMatching=true`  
  可升格为构建错误; AGP 10.0 起默认强制为致命错误.

## AGP 9.5

- 状态: 稳定 9.5.0, 2026 年 10 月与 Studio Rabbit 2 同发, 是调查日的最新稳定线.
- 自动化备份与恢复测试 (实验性): `gradle.properties` 设  
  `android.experimental.testSuiteSupport=true` 与 `android.experimental.enableBackupTest=true`,  
  在 `testOptions.backupTests` 块声明测试套件; AGP 生成并运行 JUnit 5 测试,  
  先往 app 写测试数据, 再执行备份恢复并校验数据完好; 覆盖本地, 云端与设备间迁移.
- 一批与本仓库环境相关的修复: JDK 25 下 `generateReleaseRFile` 警告 (553121473),  
  Gradle 9.8.0 的 `Configuration.setVisible()` 弃用告警 (565740572 与 560282299),  
  `l8DexDesugarLib` 把约 366 MB 的 mapping.txt 重写成 25 字节桩 (532206373).

## AGP 9.6

- 状态: 仅 alpha, 最新 9.6.0-alpha02, 与 Studio Rabbit 3 Canary 2 同发;  
  无 beta, RC 或稳定版.
- 兼容要求两站不一致, 如实记录: 镜像站 (页尾更新日期较新) 写 Gradle 最低与默认 9.7.1,  
  主站较旧抓取写 9.6.0; 本篇采纳 9.7.1.
- instrumented test 的设备端代码覆盖率 (实验性): `gradle.properties` 设  
  `android.experimental.androidTest.coverage.useOnDeviceAgent=true` 与  
  `android.experimental.reportAggregationSupport=true`. 构建期不再用 JaCoCo 插桩 app 类,  
  而是把 coverage agent 塞进 test APK, 在设备上运行时插桩; 新增随版本同版的 agent 库  
  `com.android.tools.test:coverage-agent`; 要求 app 可调试且设备 Android 9 (API 28)+.
- alpha02 修复 R8 任务不安全读取系统属性 (567815521).
