## 查了什么

Android Gradle 插件 (AGP) 在这条仓库上的版本范围是 9.1 到 9.5, 向上还有 9.6 和 10.0 两条线.  
这次查了三样东西:

1. [01-上游发布线](01-上游发布线.md): 每条线的门槛, 新特性, 修复, 以及发到哪一步.
1. [02-对本仓库的要求](02-对本仓库的要求.md): 从上游推出来的要求, 分必须做的和可以不做的.
1. [03-仓库现状](03-仓库现状.md): 拿文件核过一遍的结果, 没验到的部分, 以及要动的地方.

## 四条结论

- 仓库的写法已经落在 9.5 这条线上, Gradle, JDK, KGP, Build Tools 四道门槛都够.
- 10.0 的移除清单里, 仓库只踩中一处: `AndroidApplicationConventionPlugin.kt` 里的 `buildConfigField`.
- 9.3 之后的新写法都留着旧的写法, 仓库用的还是旧写法.
- CI 只构建 debug 变体, release 上的 R8 行为在 CI 里没有验证过.
