# AGP 9.x 到 10.0 调查 (2026-10-30)

> **状态**: **frozen**. 记的是 2026-10-30 查到的上游发布状态, 以及仓库当天的写法.  
> **调查者**: WorkBuddy CN, 模型 DeepSeek-V4.1-Flash, effort: high.  
> 这份笔记不规定代码该怎么做. 要变成规矩, 写进 [09-构建约定](../../../agents-cn/09-构建约定.md).

Android Gradle 插件 (AGP) 在这条仓库上的版本范围是 9.1 到 9.5, 向上还有 9.6 和 10.0 两条线.
调查分三份:

1. [01-版本与门槛](01-版本与门槛.md): 每条发布线的发布日期, 最低版本要求, 以及这一版加了什么.
1. [02-迁移指南](02-迁移指南.md): 9.0 起的新 DSL 与内置 Kotlin, 9.x 的过渡开关, 10.0 删掉什么换成什么.
1. [03-仓库核对](03-仓库核对.md): 逐条拿文件核过一遍的结果, 实测命令的输出, 以及到 10.0 之前要做的事.

三条结论:

- 仓库的写法已经落在 9.5 这条线上, Gradle, JDK, KGP, Build Tools 四道门槛都够.
- 10.0 的移除清单里, 仓库只踩中一处: `AndroidApplicationConventionPlugin.kt` 里的 `buildConfigField`.
- 9.3 之后的新写法都还能不采用, 不采用不等于违规.
