# 03-行为变化与新特性

> **状态**: **frozen**. 记下写下时查到的现状与结论.  
> 本节上游内容全部转述未核: 出处为官方 release notes 各版本段与官方博客, 链接见文末.  
> 项目侧判断当场核过, 依据是 02 节的用法盘点.

## 升级后可见的行为变化

1. 文本行高优化默认开启: 单行高的计算换了实现, 官方注记文本度量 (高度, 选区路径)  
   可能差几个像素. 本项目三个列表页和设置页全是文字密集的卡片, 升级后要在真机上  
   过一遍四个页面, 顺带看读屏行为 (这版修了 LazyColumn 读屏滚动焦点丢失, 是正向变化).  
   (转述未核: compose-ui release notes [I5575a] 与 [I463bc])
1. 相同静态 `ImageVector` 在同尺寸同配置下共享光栅绘制缓存, 省显存与纹理上传.  
   项目图标走 `painterResource` 的 drawable, 这项优化受益有限.  
   (转述未核: compose-ui release notes [I91b41])
1. Material3 组件级变化, 对应组件本项目都未用到: `SecureTextField` 默认混淆模式改为  
   `TextObfuscationMode.System`; `ModalBottomSheet` 与 `BottomSheetScaffold` 不再按高度启发式  
   自动移除 `PartiallyExpanded` 锚点; checkbox 尺寸与指示器按规范重新校准.  
   (转述未核: compose-material3 release notes 1.5.0 段)

## 转正的 API (不再需要 OptIn)

- `TopAppBar` 系与 `TopAppBarScrollBehavior`: 影响 02 节说的 OptIn 清理.
- Material3 侧还有 `BottomAppBar`, `SearchBarState` 与槽位式 `SearchBar`, 多选 `Carousel` 核心 API,  
  `BasicAlertDialog`, `LocalRippleThemeConfiguration`.
- animation 侧: deferred transition 全系 (`rememberDeferredTransition`, `DeferredAnimatedContent`,  
  `DeferredAnimatedVisibility` 等), `createChildTransition`, `Transition.Crossfade`,  
  `veilOut` / `unveilIn`.
- 新 artifact `material3-ripple` (内缩焦点环): 独立设计系统才需要直接依赖,  
  本项目走 MaterialTheme, 不新增依赖. (转述未核: compose-material3 与 compose-animation release notes)

## 新 API 里对本项目有意义的

- `computedStateOf` (runtime): 按需计算, 结果不缓存, 官方说多数场景建议替代 `derivedStateOf`;  
  适合缓存不划算的计算: 结果不靠对象身份, 不分配大对象, 不读很多 state, 单帧内不被读很多次.  
  项目现在没有 `derivedStateOf`, 以后写新代码时把它当默认选择.  
  (转述未核: compose-runtime release notes 1.13.0 段)
- M3 `Text` 的 `ColorProducer` lambda 重载: 在绘制阶段更新文字颜色, 不触发重组.  
  列表卡片的状态色文字以后如果要动起来, 这是免重组的写法.  
  (转述未核: compose-material3 release notes)
- `MaterialTheme.motionScheme` 统一取用动效方案 (`LocalMotionScheme` 已弃用):  
  以后新动效从这里取参数. (转述未核: compose-material3 release notes)

## 用不上的新特性 (记录在此, 防止以后误判为缺失)

- 渐进式模糊: `Modifier.blur { ... }` 配 `BlurRadiusSpec`, 支持线性渐变, 径向渐变与自定义  
  AGSL RuntimeShader.
- `PolygonShape` / `MorphPolygonShape` (foundation), 对话框与弹窗的 `blurBehindRadius` /  
  `scrimAlpha` / `windowShape`, `WindowInfo.isCrossWindowBlurEnabled`.
- Material3 Expressive 组件转正一批: `ToggleButton` 系, `SplitButton`, `ButtonGroup`,  
  波浪进度指示器, `FloatingToolbar`, 富化的 `TimePicker`. 上面这些多为检测列表用不上的装饰性组件.
- 状态存疑项: `MaterialShapes` 在转述材料里一处列为已转正, 另一处列为仍实验, 两处矛盾.  
  采用前先对 compose-material3 release notes 原文核实. (转述未核, 冲突待核)  
  (转述未核: 官方博客的图形与 Material3 章节)

## 性能与工具

- `VectorPainter` 缓存共享, LinkAnnotation 系列性能修复, `isMinimalistLocalsEnabled` 默认开启:  
  跟随升级自动生效, 不需要改代码. (转述未核: compose-ui release notes)
- 官方博客提到一套零配置的静态分析检查, 覆盖状态稳定性, 惰性布局, 图形, 动画等七类,  
  以 skill 形式提供, 不新增依赖. (转述未核: 官方博客性能章节)
