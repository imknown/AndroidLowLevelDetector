## `ListItem` 那三处的细节

被弃用的是带 `headlineContent` 的那个重载. 官方给的迁移写法是把标题放到尾随的 `content` lambda, 原来分开的  
`tonalElevation` 与 `shadowElevation` 合成一个 `elevation`. 新重载还多了 `enabled`, `verticalAlignment`,  
`shapes`, `contentPadding`.

项目这三处都传了 `ListItemDefaults.colors(containerColor = Color.Transparent)`, 这个调用在新旧重载里都在.

签名好改, 默认值才是要留意的. 新重载换了形状和内容内边距的默认值, 而 `SettingsSwitchRow`  
(`ui/settings/SettingsScreen.kt:369-372`) 那段注释是照旧重载的量出来的数: 88dp 最小高度, 16dp 与 12dp 内边距,  
`bodyLarge` 加 `bodyMedium`, 16dp 间隔. 迁完设置页要跟旧截图对比, 这一段注释也得重新核.

核实程度: 迁移写法与默认值的变化转述未核 (出处: material3 `ListItem` 的 API 参考页, 弃用说明写明  
"Use the overload where `headlineContent` is now a trailing `content` lambda"); 三处行号当场核过.

## `TopAppBar` 那行的细节

`ui/AppRoot.kt:142` 写的是 `@OptIn(ExperimentalMaterial3Api::class) // TopAppBar is still an experimental API in m3 1.4.0`.  
1.5.0 把 `TopAppBar` 和它的几个变体转成稳定, API 参考页上这些重载只剩 `@Composable`. 也就是说那行注释点名的  
版本前提不成立了, 这个 `@OptIn` 不再需要.

`AppRootShell` 里只用了 `TopAppBar` 和 `TopAppBarDefaults.topAppBarColors`, 没有用滚动行为,  
所以 1.5.0 把 `pinnedScrollBehavior` 的参数从 `isAtTop` 改成 `isAtStart` 那条不影响它.

核实程度: 转述未核 (出处: 2026 年 11 月发布博客的稳定化清单, 以及 material3 `TopAppBar` 的 API 参考页,  
两处都没有实验性注解); 项目侧的调用点当场核过.

## ScrollBarExt 那份实现的来路

`ui/common/ScrollBarExt.kt:30-33` 的注释写着这个文件是官方 `Modifier.nonInteractiveScrollbar` 的临时替代,  
"等它出现就删掉这个文件". 那个修改器在 material3 1.5.0 里出现了, 1.5.0 没让这里退化.  
那份注释说的是一个早就写好的计划, 现在到了能执行的时候. 具体怎么换见 03.

核实程度: API 参考页标 "Added in 1.5.0", 项目侧注释当场核过; 换法涉及默认值差异, 见 03 的代价一栏.
