# 02 行为变更与弃用

> **状态**: **frozen**. 这份调查写在 2026-11-20, 结论不改, 后来的更正留在原处.

这一篇只列 1.13.0 相对 1.12.1 真正带来的变化, 每条后面写本仓库的核对结果.  
核对方式是全仓库检索 `app`, `base`, `binderDetector` 三个模块的 Kotlin 源码.

## 源码不兼容的变更

| 变更 | 落在哪个版本 | 本仓库 |
|---|---|---|
| `MediaQuery` 里的 `Posture` 类换成 `WindowPosture`, 显式的 Book 姿态移除, 新增 `isTabletop` 和 `isFlat` | compose-ui 1.13.0-beta01 | 没有用到 `Posture`, 也没有用自适应库 |
| Material 3 的 `Slider` 和 `RangeSlider` 无状态重载弃用, `onValueChange` 变成必填参数且换了位置, `RangeSliderState` 的 `activeRangeStart` 和 `activeRangeEnd` 改名成 `startValue` 和 `endValue` | material3 1.5.0 | 没有用到 `Slider` |
| `Modifier.border` 换成新实现, 渲染时统一采用 outline 的尺寸 | compose-foundation 1.13.0-rc01 与 beta02 | 没有用到 `Modifier.border` |
| `LazyLayoutCacheWindow` 和 `LazyListPrefetchStrategy` 不再从 `LazyListState` 传, 改成传给 `LazyColumn`, `LazyRow` 这些 composable | compose-ui 1.13.0-alpha03, compose-foundation 1.13.0-alpha03 | 没有用过 `LazyLayoutCacheWindow`, 也没有自定义预取策略 |

这些条目本仓库一条都没碰到. 当场核过.

## 弃用

| 弃用的东西 | 替代物 | 本仓库 |
|---|---|---|
| `Modifier.onFocusedBoundsChanged` 的实现被移除, modifier 跑起来不再有效果 | `FocusTargetModifierNode.getFocusedRect()`, `Modifier.onFocusChanged`, `BringIntoViewRequester` | 没有用到 |
| value 版的 `BasicTextField` 重载 | 状态版 `BasicTextField` 配 `TextFieldState` | 没有用到任何 `TextField` |
| `VisualTransformation` | `OutputTransformation` 与 `InputTransformation` | 没有用到 |
| Material 2 整个库不再维护 | Material 3 | 只引了 material3, 没有引 Material 2 |
| `LazyListPrefetchStrategy`, `LazyListPrefetchScope`, `LazyListPrefetchResultScope` | `LazyLayoutCacheWindow` | 没有用到 |
| Material 3 的 `LocalMotionScheme` | `MaterialTheme.motionScheme` | 没有用到 |
| `InputTransformation.maxLength` | `maxLengthTrim` 和 `maxLengthReject` | 没有用到 |

上游 blog 提到 value 版 `BasicTextField` 是在 1.13 弃用的, 同时 `VisualTransformation` 跟着弃用. 当场核过.  
Material 3 的 value 版 `TextField` 在 1.5.0 还没有弃用, 上游只是建议迁移. 当场核过.

`Modifier.onFocusedBoundsChanged` 这条要说清楚: 上游在 1.12 弃用它, 1.13 把实现删掉了,  
所以它还在也不会报错, 只是不起作用. 当场核过.

## 行为变化

### clickable 会播系统交互音效

`Modifier.clickable` 现在会自动播 Android 平台标准的交互音效, 跟着用户的系统声音设置走.  
落点是 compose-foundation 1.13.0-alpha01. 当场核过.

本仓库有三处用到 `Modifier.clickable`:

- `app/src/main/java/net/imknown/android/forefrontinfo/ui/settings/SettingsScreen.kt:218`
- `app/src/main/java/net/imknown/android/forefrontinfo/ui/settings/SettingsScreen.kt:236`
- `app/src/main/java/net/imknown/android/forefrontinfo/ui/settings/SettingsScreen.kt:304`

升级后这三处会开始出声. `SettingsScreen.kt:342` 的 `selectable` 和 `:379` 的 `toggleable`  
也建在 `clickable` 上, 同样会出声. 当场核过.

想关掉的话, 上游给的是 `SoundEffectOnInteraction` 这个 composable 用来退出. 当场核过.

### 文字的单行行高优化默认开启

compose-ui 1.13.0-alpha03 把单行行高优化默认打开了, 上游说文字的高度和选区路径这类度量可能差几个像素.  
落点是 compose-ui 1.13.0-alpha03. 当场核过.

本仓库的 UI 走 Material 3 的 `Text`, 语言有 `zh-rCN`, `zh-rTW`, `fr-rFR` 三种 (见 `app/build.gradle.kts` 的 `localeFilters`).  
CJK 字体在行高上更容易看出差别, 升级后要在真机上过一遍页面. 当场核过.

### CompositionLocal 的解析方式变了

compose-ui 1.13.0-alpha03 把 `isMinimalistLocalsEnabled` 默认打开, CompositionLocal 改成从 `LocalOwner`  
和 `LocalAndroidComposeView` 按需动态解析. 当场核过.

本仓库用到的 CompositionLocal 是这些:

- `LocalContext`, `LocalConfiguration`, `LocalResources`, `LocalDensity`, `LocalActivity` (Compose 自带)
- `LocalExtendedColors` (`ui/theme/ExtendedColors.kt:39`), `LocalThemeMode` (`ui/theme/Theme.kt:293`),  
  `LocalScrollBarMode` (`ui/base/list/MyModelListScreen.kt:39`) (本仓库自己定义的三个)

后三个都用 `staticCompositionLocalOf` 或 `ProvidableCompositionLocal` 定义, 并且都有读取方.  
上游没有列出被精简掉的 local 名单, 这条要在真机上目视确认主题切换和设置页没跑偏. 当场核过.

### Material 3 1.5.0 里几处组件行为

| 组件 | 变化 | 本仓库 |
|---|---|---|
| `ModalBottomSheet`, `BottomSheetScaffold` | 不再按布局高度启发式自动去掉 `PartiallyExpanded` 锚点, 拖动时改用 `MaterialTheme.motionScheme` | 没有用到 BottomSheet |
| `Checkbox` | 方框尺寸和勾选标记按 Material 3 规范重新校准, 有 flag `ComposeMaterial3Flags.isCheckboxStylingFixEnabled` 可回退 | 没有用到 Checkbox |
| 横向 `NavigationItem` | 高对比度主题下标签色改用 `selectedTextColorStartIconPosition` 算 | 没有用到 NavigationItem |
| `TopAppBarDefaults` | `pinnedScrollBehavior` 与 `enterAlwaysScrollBehavior` 的重载改成接 `ScrollableState`, `isAtTop` 改名 `isAtStart` | 用了 `TopAppBar` 和 `TopAppBarDefaults.topAppBarColors`, 没有用 scrollBehavior |
| `SecureTextField`, `OutlinedSecureTextField` | 默认遮蔽模式改成 `TextObfuscationMode.System` | 没有用到 |

这些条目本仓库都没碰到. 当场核过.

`TopAppBar` 一条顺带说一句: Material 3 1.5.0 把 `TopAppBar` 列为稳定 API,  
`app/src/main/java/net/imknown/android/forefrontinfo/ui/AppRoot.kt:142` 的  
`@OptIn(ExperimentalMaterial3Api::class)` 和它那句注释就不再需要了. 当场核过.

### 其它

- `Modifier.border` 的新实现支持用 `ShaderBrush` 配运行时着色器画任意多边形形状. 当场核过.
- `BasicTextField` 在窗口还没拿到焦点时请求焦点, 不再立刻拉起软键盘, 等窗口拿到焦点才开输入会话.  
  有 flag `ComposeFoundationFlags.isTextFieldWaitWindowFocusForInputSessionEnabled` 可回退. 当场核过.  
- Compose 嵌在 View 滚动容器 (`ScrollView`, `NestedScrollView`, `CoordinatorLayout`) 里时,  
  快速滚动的速度计算修好了, 交接不会突然停住. 当场核过.  
- `VectorPainter` 在多个 composable 渲染同一个 `ImageVector` 时共享光栅化缓存, 默认打开,  
  可用 `ComposeUiFlags.isVectorDrawCacheSharingEnabled` 关掉. 当场核过.  
  本仓库的图标走 `painterResource(tab.iconRes)` (`ui/AppRoot.kt:169`), 来自 drawable 资源,  
  代码里没有 `ImageVector` 实例, 这条优化在这里没有对应的收益. 当场核过.  
- `computedStateOf` 的计算块被限制成只读, 在里面写 state 会抛 `IllegalStateException`. 当场核过.
- 传 `Float.NaN` 或 `Double.NaN` 给 composable 参数导致永远不跳过重组的 bug 修好了.  
  `Dp.Unspecified` 背后就是 `Float.NaN`, 所以过去带 `Dp.Unspecified` 的参数永远不跳过重组.  
  本仓库没有用到 `Dp.Unspecified`. 当场核过.
