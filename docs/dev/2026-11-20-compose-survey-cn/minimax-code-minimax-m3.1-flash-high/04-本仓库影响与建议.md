## 同一批改动里可以顺手清掉的

`app/src/main/java/net/imknown/android/forefrontinfo/ui/AppRoot.kt:142` 的  
`@OptIn(ExperimentalMaterial3Api::class)`, 连带 `:11` 的 `import androidx.compose.material3.ExperimentalMaterial3Api`,  
和那句写着 "TopAppBar is still an experimental API in m3 1.4.0" 的注释. 当场核过.

Material 3 1.5.0 把 `TopAppBar` 列为稳定 API. 这个文件里没有别的实验 API,  
所以这一个 OptIn 去掉之后不会出现新的编译错误. 当场核过.

## 升级后要目视确认的两处

### 交互音效

`Modifier.clickable` 开始播系统交互音效. 会被点到的地方:

- `ui/settings/SettingsScreen.kt:218`, `:236`, `:304` (直接用 `clickable`)
- `ui/settings/SettingsScreen.kt:342` (`selectable`), `:379` (`toggleable`)

`selectable` 和 `toggleable` 都建在 `clickable` 上, 同样会出声. 当场核过.

要是不想要这个声音, 上游给的办法是用 `SoundEffectOnInteraction` 这个 composable 退出. 当场核过.  
想不想退出是产品决定, 这一条归负责人定. 当场核过.

### 文字行高

单行行高优化默认打开, 文字的高度和选区路径可能差几个像素. 当场核过.  
本仓库支持 `zh-rCN`, `zh-rTW`, `fr-rFR` 三种语言, 中文对行高敏感. 当场核过.

装到真机上过一遍设置页和四个列表页, 看文字有没有挤或者撞行. 当场核过.

另外顺手看一眼主题切换 (深浅色) 和设置项的开关状态. CompositionLocal 的解析方式在 1.13.0 变了,  
本仓库自己定义了三个 CompositionLocal, 上游没列出被精简掉的名单, 所以只能靠目视. 当场核过.

## 可以采用的写法

按对本仓库的价值排:

1. `LazyLayoutCacheWindow`. 两处 `LazyColumn` (`ui/settings/SettingsScreen.kt:155`,  
   `ui/base/list/MyModelListScreen.kt:112`) 的列表项高度不固定, 正是这个 API 的适用场景.  
   1.13.0 里它从 `LazyListState` 挪到了 `LazyColumn` 上, 配法跟旧版不一样. 当场核过.

1. `LineHeightStyle.Mode.PerLine`. 多语言界面里每行单独算行高, 高字形不跟相邻行撞.  
   本仓库三种语言里有两种是 CJK. 当场核过.

1. `computedStateOf`. 以后写 "从几个状态算出一个条件" 的代码时用它, 不用 `derivedStateOf`.  
   现在仓库里一个 `derivedStateOf` 都没有, 这条是给以后用的规则. 当场核过.

1. `CapturedAnimatedVisibility`. 以后做 "详情面板关掉时播退出动画" 的界面时用它,  
   退出期帧时间比 `AnimatedVisibility` 快 7 到 8 个百分点. 当场核过.
