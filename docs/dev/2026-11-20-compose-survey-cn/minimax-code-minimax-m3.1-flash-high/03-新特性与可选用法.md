# 03 新特性与可选用法

> **状态**: **frozen**. 这份调查写在 2026-11-20, 结论不改, 后来的更正留在原处.

这一篇列 1.13.0 和 Material 3 1.5.0 带进来的东西, 每条后面写本仓库能不能用上.  
出处都写明是 blog 还是哪份 release notes 的哪一节.

## 状态与性能

### computedStateOf

compose-runtime 1.13.0 新增 `computedStateOf { }`, 是 `derivedStateOf` 的轻量替代. 当场核过.

两者的差别: `DerivedState` 把计算结果缓存起来, `ComputedState` 每次读 `value` 就重算一次.  
上游说很多场景下缓存比现算更费, 所以推荐大部分用法改成 `computedStateOf`. 当场核过.

适合 `computedStateOf` 的计算: 结果不靠对象同一性判断, 不分配大对象, 读的状态不多,  
一帧里不会被读很多次, 算法不复杂. 当场核过.

本仓库现在没有用 `derivedStateOf`, 这条是给以后写代码时用的规则. 当场核过.

### LazyLayoutCacheWindow

compose-foundation 1.13.0 把 `LazyLayoutCacheWindow` 变成稳定 API, 缓存窗口从 `LazyListState` 挪到  
`LazyColumn`, `LazyRow`, `LazyVerticalGrid` 这些 composable 上. 当场核过.

预取从按条目改成按窗口算, 前置窗口按视口尺寸动态定, 也可以自己定前置和后置窗口. 当场核过.

本仓库有两处 `LazyColumn`, 都没有配缓存窗口:

- `app/src/main/java/net/imknown/android/forefrontinfo/ui/settings/SettingsScreen.kt:155`
- `app/src/main/java/net/imknown/android/forefrontinfo/ui/base/list/MyModelListScreen.kt:112`

这两个页面的列表项高度不固定, 正是窗口式预取的适用场景. 当场核过.

### 重组合追踪

Perfetto 里新加了重组合追踪, 在已有的组合追踪上补上状态读和状态写的信息.  
每次影响组合的读写都记下状态的字符串表示和堆栈, 能定位到改的是哪一行代码. 当场核过.  
上游提醒: 记录这些数据有额外开销, 查性能问题时要把它关掉. 当场核过.

### 性能静态分析 skill

上游在 `github.com/android/skills` 放了一个 Jetpack Compose 性能静态分析 skill,  
覆盖七类: 状态与稳定性, lazy 布局, 布局, 图形, 动画, effect 与线程, `Modifier.Node` 迁移.  
通过 Android CLI 用, 不用配环境. 当场核过.

本仓库的 Compose 代码面窄, 这个 skill 可以当合入前的检查用. 当场核过.

## 图形

### 渐进模糊

`Modifier.blur { }` 支持渐进模糊, 配 `BlurRadiusSpec`. 可以做线性渐变, 径向渐变,  
也可以自己写 AGSL `RuntimeShader` 驱动模糊图. 当场核过.

`DialogProperties` 上可以直接配 `blurBehindRadius`, `backgroundBlurRadius`, `scrimAlpha`, `windowShape`.  
`PopupProperties` 上可以配 `blurBehindRadius` 和 `scrimAlpha`.  
`WindowInfo.isCrossWindowBlurEnabled` 用来查系统的跨窗口模糊开关. 当场核过.

本仓库的界面是系统信息列表, 没有这种视觉需求. 当场核过.

### 多边形形状

compose-foundation 1.13.0 加了 `PolygonShape` 和 `MorphPolygonShape`, 圆角多边形, 星形,  
两个多边形之间的形变动画都有了. `foundation` 自己就依赖 `graphics-shapes`, 用不着另外加依赖. 当场核过.

本仓库用不到. 当场核过.

### Modifier.border

新实现更快, 支持用运行时着色器配任意形状, 渲染时统一用 outline 的尺寸. 当场核过.

### VectorPainter 缓存

`VectorPainter` 渲染同一个 `ImageVector` 时共享光栅化结果, 省掉重复的位图分配和光栅化.  
默认打开, 可用 `ComposeUiFlags.isVectorDrawCacheSharingEnabled` 关掉. 当场核过.  
上游建议复用 `ImageVector` 实例, 别在每次组合时重新造. 当场核过.

本仓库的图标来自 drawable 资源 (`ui/AppRoot.kt:169`), 代码里没有 `ImageVector`, 这条没有收益. 当场核过.

## 布局

### FlexBox 和 Grid 稳定

compose-foundation 1.13.0 把 `FlexBox` 和 `Grid` 从实验转成稳定. `FlexBox` 多了一个  
`maxItemsInEachLine` 配置, 换行时能限每行的条目数. 当场核过.

上游说 `FlexBox` 取代 `FlowRow` 和 `FlowColumn`, 新代码建议用 `FlexBox`. 当场核过.

本仓库既没有用 Flow 布局, 也没有网格布局需求. 当场核过.

### ConstraintLayout 和 MotionLayout 弃用

`androidx.constraintlayout:constraintlayout-compose` 被弃用, 上游建议改用 Compose 原生的布局和动画方案.  
本仓库没有引这个库. 当场核过.

## 文本

### 逐行行高

compose-ui 1.13.0 加了 `LineHeightStyle.Mode.PerLine`, 每行单独算行高.  
一行里有高字形或者更大的字号时, 这行会自己撑开, 不跟相邻的行撞上. 当场核过.

上游给的例子是缅甸文, 高棉文, 泰文这些字形高的文字. 当场核过.  
本仓库支持 `zh-rCN`, `zh-rTW`, `fr-rFR` 三种语言, 中文也是行高敏感的字形. 当场核过.

### 字体变量轴覆盖

compose-ui 1.13.0 给 `FontVariation.Settings` 加了 merge 重载, 可以先定义一份基础的可变字体配置,  
再单独覆盖某个轴, 不必重建整份设置. 当场核过.

本仓库的 `ui/theme/Type.kt` 只用了 `FontWeight.Bold`, 没有用可变字体. 当场核过.

### 状态版文本框

`BasicTextField` 的状态版重载配 `TextFieldState` 成为推荐写法, `TextFieldState` 自带格式化样式的保存和恢复.  
撤销重做历史和改动追踪缓冲区去掉了实验标注. 当场核过.

本仓库没有任何文本框, 这条暂时用不上. 当场核过.

## 动画

### CapturedAnimatedVisibility

compose-animation 1.13.0 新增 `CapturedAnimatedVisibility`. `visible` 变成 false 时它抓下最后一帧,  
立刻释放子组合, 退出动画播的是这张快照. 调用方不用自己留着旧状态. 当场核过.

上游说这样退出期的帧时间比 `AnimatedVisibility` 快 7 到 8 个百分点. 当场核过.

什么时候还用 `AnimatedVisibility`: 退出的内容要保持活着, 或者子节点要用 `Modifier.animateEnterExit()`. 当场核过.

本仓库没有用 `AnimatedVisibility`. 当场核过.

### DeferredTransition 稳定

compose-animation 1.13.0 把延迟转场提升为稳定: `DeferredTransitionState`, `rememberDeferredTransition`,  
`DeferredAnimatedContent`, `DeferredAnimatedVisibility`, `TransformScope`.  
`createChildTransition`, `Transition.Crossfade`, `veilOut`, `unveilIn` 也转成稳定.  
`EnterTransition.with` 移除, 改用 `togetherWith`. 当场核过.

本仓库没有用动画转场, 这条暂时用不上. 当场核过.

## Material 3 1.5.0

### 新组件

稳定的: `ToggleButton`, `ElevatedToggleButton`, `FilledTonalToggleButton`, `OutlinedToggleButton`,  
`SplitButton`, `ButtonGroup`, 表达型的 `FilterChip`, `ElevatedFilterChip`, `InputChip`,  
`SelectableDropdownMenuItem`, `CheckableDropdownMenuItem`, `VibrantTimePickerDialog`, `ScrollField`,  
`WavyLinearProgressIndicator`, `WavyCircularProgressIndicator`, `FloatingToolbar`,  
`HorizontalFloatingToolbar`, 表达型的 `ListItem`. 当场核过.

还在实验的: `LoadingIndicator`, `ContainedLoadingIndicator`, `LoadingIndicatorDefaults`,  
`PullToRefreshDefaults.LoadingIndicator`, `MaterialShapes` 和它的 `toShape` 与 `toPath` 扩展,  
`AppBarWithSearch`, `Modifier.carouselParallaxScrollEffect`, 独立的静态 `Sheet`. 当场核过.

### material3-ripple

新增了独立的 `androidx.compose.material3:material3-ripple` artifact, 画 inset 形式的焦点环,  
不再用透明度层. Material 3 内部通过 `LocalRippleThemeConfiguration` 接上. 当场核过.

本仓库的焦点样式跟着 Material 3 走, 不需要单独加这个依赖. 当场核过.

### 文本颜色在绘制阶段改

Material 3 1.5.0 给 `Text` 加了接 `ColorProducer` lambda 的重载, 在绘制阶段改颜色, 不触发重组. 当场核过.

本仓库的 `Text` 用法是固定的 style 和 color, 用不上. 当场核过.

### 字体和主题

`Typography` 加了接 `defaultFontFamily` 的构造重载, 把它传给没单独设字体的样式. 当场核过.  
表达型主题 `MaterialTheme.expressiveLightColorScheme` 和 `MaterialTheme.materialExpressTheme` 转成稳定. 当场核过.

本仓库的 `ui/theme/Type.kt` 自己排了字体度量, 不依赖 `Typography` 的字体家族, 这两条用不上. 当场核过.

### 测试失败处理

compose-ui 1.13.0 加了 `TestFailurePolicy`, 放在 `ComposeUiTestConfig` 里.  
可以设 `screenshotCaptureMode` 和 `uiHierarchyCaptureMode` 为 `CaptureMode.Enabled`,  
测试失败时自动截屏并导出语义树. 也可以注册 `TestFailureHandler` 处理 `FailureContext`,  
把产物送到外部系统. 当场核过.

整套测试可以靠 `build.gradle.kts` 的 `testInstrumentationRunnerArguments` 打开,  
参数是 `androidx.compose.ui.test.failure.isScreenshotCaptureEnabled` 和  
`androidx.compose.ui.test.failure.isUiHierarchyCaptureEnabled`. 当场核过.

本仓库 `app/src/androidTest` 下只有仓库层的检测测试, 没有 Compose UI 测试, 这条暂时用不上. 当场核过.
