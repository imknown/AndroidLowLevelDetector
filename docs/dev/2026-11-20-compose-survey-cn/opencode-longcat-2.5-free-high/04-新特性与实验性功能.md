# 04-新特性与实验性功能

> **状态**: **frozen**.

按模块盘点 1.13.0 与 material3 1.5.0 的新增 API, 以及本仓库是否用得上.

## runtime 1.13.0

- `computedStateOf`: 不缓存结果, 每次读值时现算. 官方建议大多数场景用它替代 `derivedStateOf`, 重计算或确实需要缓存时才用后者.  
  本仓库未用 `derivedStateOf`, 属新代码写法建议.  
  核实程度: 当场核过 (runtime 1.13.0 release notes).
- 实验性 `SlotTable` (`LinkComposer`) 仍是 opt-in, proguard 语法有变.  
  本仓库没有开这个 flag.  
  核实程度: 当场核过.

## foundation 1.13.0

- `PolygonShape` / `MorphPolygonShape`: 规则多边形与星形, 带圆角平滑, 可在 draw 阶段按 progress 形变.  
  本仓库未用.  
  核实程度: 当场核过.
- `LazyLayoutCacheWindow` 转正: 缓存与预取配置从 scroll state 移到 `LazyColumn` 等 composable 上, 默认走窗口预取.  
  本仓库的 `rememberLazyListState()` 不带参数, 自动用上新默认.  
  核实程度: 当场核过.
- `LineHeightStyle.Mode.PerLine`: 按行算行高, 防多语言混排撞行.  
  本仓库只有 zh-rCN, zh-rTW, fr-rFR, 用不上.  
  核实程度: 当场核过.
- `FontVariation.Settings` 新增 `merge` 重载. 本仓库未用.  
  核实程度: 当场核过.
- `Modifier.border` 换实现, 支持 RuntimeShader. 本仓库未用.  
  核实程度: 当场核过.

## compose ui 1.13.0

- 渐进模糊 `Modifier.blur { }` 与 `BlurRadiusSpec`, 可配线性/径向渐变或自定义 AGSL RuntimeShader.  
  本仓库未用.  
  核实程度: 当场核过.
- `DialogProperties` 新增 `blurBehindRadius`, `backgroundBlurRadius`, `scrimAlpha`, `windowShape`;  
  `PopupProperties` 新增 `blurBehindRadius`, `scrimAlpha`; `WindowInfo.isCrossWindowBlurEnabled`.  
  本仓库未用.  
  核实程度: 当场核过.
- `LocalWindow` CompositionLocal: 在组合里取当前 `android.view.Window`.  
  本仓库未用.  
  核实程度: 当场核过.

## animation 1.13.0

- `DeferredTransition` 一族转正: `DeferredTransitionState`, `rememberDeferredTransition`, `DeferredAnimatedContent`, `DeferredAnimatedVisibility`, `TransformScope`.  
  本仓库未用.  
  核实程度: 当场核过.
- `CapturedAnimatedVisibility`: 隐藏时立刻 dispose 子组合, 用 GraphicsLayer 动画最后一帧, 退出阶段帧耗时少 7% 到 8%.  
  本仓库未用 `AnimatedVisibility`.  
  核实程度: 当场核过 (官方发布博客).
- `createChildTransition`, `Transition.Crossfade`, `veilOut`, `unveilIn` 转正.  
  本仓库未用.  
  核实程度: 当场核过.

## material3 1.5.0

- 新组件: `ToggleButton` 系列, `SplitButton`, `ButtonGroup`, expressive `TextField` 样式, expressive chips,  
  `SelectableDropdownMenuItem` / `CheckableDropdownMenuItem`, `VibrantTimePickerDialog`, `ScrollField`,  
  `Sheet`, `Scrim`, `WavyLinearProgressIndicator` / `WavyCircularProgressIndicator`.  
  本仓库未用.  
  核实程度: 当场核过.
- `LoadingIndicator` / `ContainedLoadingIndicator` / `MaterialShapes`: 1.5.0 里仍是实验.  
  本仓库未用.  
  核实程度: 当场核过.
- `TopAppBar` 与 variants, `BottomAppBar`, `BasicAlertDialog`, `Slider` / `RangeSlider` 核心 API, `SearchBar` 等转正.  
  本仓库用到 `TopAppBar`.  
  核实程度: 当场核过.
- `MaterialExpressiveTheme` 与 `expressiveLightColorScheme` 转正.  
  关系到 issue #59.  
  核实程度: 当场核过.
- `material3-ripple` 新构件, 用 inset focus ring 画焦点. 本仓库没有直接用 `material-ripple`.  
  核实程度: 当场核过.
- `PullToRefreshBox` 新增 `enabled` 与 `threshold` (1.5.0-alpha15 引入).  
  本仓库 `MyModelListScreen.kt:95` 传了自定义 state 与 indicator, 这两个参数暂时用不上.  
  核实程度: 当场核过.
