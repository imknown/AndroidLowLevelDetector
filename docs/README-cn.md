## 约定

- 每条需求和发现都有 ID (需求用 `FR-x`/`AC`, 架构决策用 `ADR-x`, 体检发现用 `AR-xx` 和 `C`/`R`/`A`, 开放问题用 `Q-x`). ID 在所有文档间通用 — 引用时用 ID.
- **就地修正**文档: 一句话被证明是错的, 就改写它以及所有依赖它的下游内容, 让文档单独读来就是当前事实. 不要让被推翻的句子原样留着, 后面再挂一个括号或引块更正; 也不要给改过的句子标注是哪次体检改的 — 事实属于句子本身, 不属于谁在何时核对过的说明.
- 上一条规则的适用范围: [dev/README-cn.md](dev/README-cn.md#开发者文档) 中标为 **living** 的文档 — 规格, 约定, 一切描述现状的东西. 在那里声明为 **frozen** 或 **record** 的文档 (已完成的迁移计划, View 时代的架构体检及其快赢清单) 保留写作时的文本, 包括其中的更正与后续发现: 引用它们做历史, 但不要把今天的代码回填进去. 没有任何文档默认被冻结; 新文档在它的 README 另行说明之前都是 living.
- 有冲突先问再裁: 两份文档不一致, 或文档与代码不一致且证据不能判定谁错时, 把两边摆出来让负责人裁定 — 然后只改被裁定的那句. 更正不外溢: 另一句看起来像同样问题的话, 记到待问清单里, 不并进同一次修改.
- 文档只陈述负责人说过的话或代码展示的事实. 不为了让一行或一句话看起来完整而添术语, 检测条目或限定词; 术语表的一行只覆盖规格本身用到的词汇, 最后一处引用已消失的行要先问, 而不是因为该术语广为人知就留着.
- 留在正文里的: 实质与导航 — 句子所划的范围或例外, 按 ID 的交叉引用 (`FR-x`, `ADR-x`, `Q9`), 代码符号. **谁在何时裁定了什么, 不是正文**: 带日期的裁定属于 [spec-cn 第 03 章](spec-cn/03-非功能需求-发布与开放问题.md)的登记行 (路线图清单与开放问题表) 或 `git log`, 不是每句话上的 "负责人裁定, <日期>" 标签. 同理, 版本行只写版本并指向 `git log`; 它不积累修订日志.
- 文档默认用英语; 非英语目录带语言后缀 (中文: `-cn`). 永远以英文版为生效版本: 英文的 `README.md` / `AGENTS.md` 保住规范文件名, 旁边配一份中文翻译 (`README-cn.md`, `AGENTS-cn.md`); 整目录的非英语版与同名无后缀英文目录成孪生 (`spec-cn/` ↔ `spec/`, 以英文为主); 某处都没有英文对应版的 `-cn` 目录, 其 `README.md` 用该目录的语言书写, 不设孪生文件. 链接跟随链接方文档的语言 — 中文文档指向中文版 (`README-cn.md` / `spec-cn/`), 英文文档指向英文版 — 没有对应版本时, 指向存在的那份. 文件名默认用英语, 但若干 `-cn` 章节文件已经用了中文名 (`01-架构.md`); 沿用各目录现有的命名. 有理由时, 文档内部仍可使用任何语言.
- **任何语言都用 ASCII 标点**: 中文 (或日文) 文档用英文标点, 不用 CJK 标点 — `,` `.` `;` `:` `!` `?` `(...)` `"..."`, 而不是 `，。；：！（）「」《》`. 一一对应: `，、` → `,` · `。` → `.` · `；` → `;` · `：` → `:` · `（）` → `()` · `「」『』《》` → `"` (嵌套时用 `'`) · `……`/`…` → `...` · `——` → ` — `. 非标点字形保持原样: `—` `·` `→` `←`, 图中的表格线符号, 以及状态 emoji.
  间距跟英语走, 不论两侧是什么文字: 标点后若还接文字, 后面空一格 (`每个条目, 每次检测`), `,` `.;:!?)` 前不空格, `(` `"` 内不空格. 另外两种情况: `(` 紧跟标识符表示调用, 中间不空格 (`collectModels()`); 数字之间的 `:` 不加空格 (`16:9`, `12:30`).
  这条对每份文档都成立, 包括 **frozen** 和 **record** 的那些 — 标点属于排版, 不是那些状态所保留的实质. 写新文字或重写一段时, 顺手把改动触及的部分一并转换; "frozen" 到底冻结什么, 见 [dev/README-cn.md](dev/README-cn.md#开发者文档).
  标题的标点和间距决定目录所指向的 GitHub 锚点, 所以重排一个标题的间距时, 要在同一次修改里改写所有解析到它的 `](#...)`. 显式 `<a id="AR-01">` 锚点是稳定文本, 永不移动.
- 任何文档 (memory 文档在内) 都不得含敏感信息: 隐私数据, 密码, 密钥, 证书.
- 保持文档简短; 一份长得太长时, 沿自然缝隙拆开, 保留一个 README 做索引页.
