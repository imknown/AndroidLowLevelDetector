# 05 新特性与本项目的相关性

> **状态**: **frozen**. 记下调查时 (2026-11-20) 这版给了什么, 以及在这个项目里用不用得上.

## 一张表看完全部

| 范围 | 这版给了什么 | 项目的情况 | 结论 |
|---|---|---|---|
| 图形 | 渐进模糊 `Modifier.blur { blurRadiusSpec = ... }` 与 `BlurRadiusSpec`, 支持线性与径向渐变, 自定义 AGSL 着色器 | 没有任何模糊需求 | 用不上 |
| 图形 | `PolygonShape` 与 `MorphPolygonShape`, 能在多边形之间做形变 | 界面只用 `CircleShape` 和 M3 的圆角形状 | 用不上 |
| 图形 | `DialogProperties` 与 `PopupProperties` 直接配模糊半径, 遮罩透明度, 窗口形状; `WindowInfo.isCrossWindowBlurEnabled` 查系统开关 | 对话框只有 M3 的 `AlertDialog`, 没有自定义窗口属性 | 用不上 |
| 图形 | `VectorPainter` 同图复用位图缓存默认打开; `Modifier.border` 换更快的实现并支持运行时着色器 | 图标是四个各不相同的矢量; 没有用 `border` | 不涉及 |
| 布局 | `FlexBox` 与 `Grid` 转稳定, `FlexBox` 多了 `maxItemsInEachLine` | 界面是 `LazyColumn` 加 `Row` / `Column`, 没有换行流式布局 | 不涉及 |
| 布局 | Compose 版的 `ConstraintLayout` 与 `MotionLayout` 弃用 | 没用 | 不涉及 |
| 布局 | `LazyLayoutCacheWindow` 转稳定, 预取从状态对象挪到列表参数 | 两个列表都是几十条, 一屏装得下 | 暂时不用, 见 03 第 5 条 |
| 文本 | 值式的 `BasicTextField` 与 `VisualTransformation` 弃用, 改成 `TextFieldState` 加 `InputTransformation` | 没有输入框 | 不涉及 |
| 文本 | `LineHeightStyle.Mode.PerLine` 逐行算行高 | 没有多语言文字混排 | 不涉及 |
| 文本 | `FontVariation.Settings` 加合并重载; `Font` 暴露 `variationSettings` | 只用系统默认字体 | 不涉及 |
| 状态 | `computedStateOf { }` 作为 `derivedStateOf` 的轻量替代, 不缓存结果 | 全仓没有 `derivedStateOf` | 不涉及 |
| 状态 | `SideEffect` 带 key 的重载; `produceState` 与 `collectAsState` 能传 `SnapshotMutationPolicy` | 没有这几处用法 | 不涉及 |
| 状态 | 嵌套快照会推进父快照, 同一状态被两边写时父的写落到最后 | 没有手写快照 | 不涉及 |
| 动画 | `DeferredTransition` 系列转稳定; 新增 `CapturedAnimatedVisibility` | 只用导航的进出场过渡 | 用不上 |
| Material3 | `TopAppBar` 各变体, `BottomAppBar`, `BasicAlertDialog`, `SearchBar`, `Slider` 转稳定 | 用了 `TopAppBar` 和 `AlertDialog` | 见 02 与 03 第 1 条 |
| Material3 | 一批表达性组件: 分段按钮, 分裂按钮, 按钮组, 波浪进度条, 加载指示器, 浮动工具栏, 35 个 `MaterialShapes`, 新的时间选择器 | 界面的目标是复刻旧 View 的样子 | 不建议 |
| Material3 | `material3-ripple` 独立构件, 焦点环改成内嵌 | ripple 目前由 `material-ripple` 提供 | 可选, 视觉会变 |
| 测试 | `ComposeUiTest` 从实验性转稳定, 测试配置改名 `ComposeUiTestConfig`, 新增 `TestFailurePolicy` 与失败时截图, 语义树捕获 | 现在没有 Compose UI 测试 | 想加测试时是条新路 |
| 测试 | 尺寸与位置断言能带容差, `captureToImage` 能带超时 | 同上 | 同上 |
| 新库 | Compose Web (`androidx.web:web`), A2UI 渲染器, `Jetpack AppState` 还在 alpha | 项目用 `androidx.webkit` 只为读 WebView 版本, 跟 Compose Web 是两件事 | 不涉及 |

核实程度: 整张表的左两列转述未核 (出处: 2026 年 11 月那份发布博客, 以及 compose-ui, compose-foundation,  
compose-animation, compose-runtime, compose-material3 各自的 1.13.0 与 1.5.0 发行说明);  
右两列是照项目代码判断的, 判断依据的搜索与文件位置记在 01 的最后一节和 02 的清单里.

## 值得留意的两处细节

`material3` 1.5.0 把实验性标注砍掉了一大半 (从一百二十多个减到五十八个), 顺手转正的东西里包含  
`TopAppBar` 和 `BasicAlertDialog`. 这不影响项目现在能不能编, 影响的是那些 `@OptIn` 和注释还准不准.

`FlowRow` 与 `FlowColumn` 没有被弃用, 官方只是说新代码用 `FlexBox`. 项目里本来就没用, 所以这条既不用改,  
也不用担心哪天编译报弃用.

核实程度: 转述未核 (出处: 发布博客的 Material3 一节与布局一节).
