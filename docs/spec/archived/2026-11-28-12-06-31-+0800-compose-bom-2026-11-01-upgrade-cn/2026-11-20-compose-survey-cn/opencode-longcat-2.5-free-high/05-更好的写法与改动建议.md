# 05-更好的写法与改动建议

> **状态**: **frozen**.

这一篇写的是升级之后值得做的改动, 按对本仓库的相关度排.  
除了第 1 条, 其余都是新代码的写法建议, 不是升级强制的.

## 1. 用官方 `Modifier.nonInteractiveScrollbar` 换掉自绘的 `ScrollBarExt.kt`

- 官方 API 参考页 `NonInteractiveScrollbarDefaults` 标着 "Added in 1.5.0"; material3 package summary 里 `nonInteractiveScrollbar` 列在 Composables, 没有标实验.  
  核实程度: 当场核过.
- 官方签名: `Modifier.nonInteractiveScrollbar(state: ScrollIndicatorState, orientation: Orientation, thumbColor, trackColor, thickness, thumbMinLength, thumbMaxLengthFraction, isFadeEnabled, fadeDurationMillis, fadeDelayMillis, mainAxisTrackInset, crossAxisTrackInset)`.  
  核实程度: 转述未核 (抄自官方 package summary 的条目, 没有逐参数核).
- 改法: 删掉 `ui/common/ScrollBarExt.kt`, 两个调用点改成传 `scrollState.scrollIndicatorState`, 原来的 `enabled` 参数变成守卫调用的条件.  
  调用点: `MyModelListScreen.kt:118`, `SettingsScreen.kt:160`.  
  核实程度: 当场核过.
- 注意: 官方那个扩展是非交互的, 所以 issue #37 的 "可拖动" 那一档仍然没有实现.  
  核实程度: 当场核过 (该文件注释原文写了 "Nothing is draggable").

## 2. 删掉 `AppRoot.kt` 的 `@OptIn(ExperimentalMaterial3Api::class)`

- `TopAppBar` 在 material3 1.5.0 的 Stable APIs 列表里.  
  要删的两处: `AppRoot.kt:142` 的注解, `AppRoot.kt:11` 的 import.  
  核实程度: 当场核过.

## 3. 条件判断与过滤状态优先 `computedStateOf`

- 官方建议大多数场景用 `computedStateOf` 替代 `derivedStateOf`; 重计算或需要缓存才用后者.  
  本仓库现在没用 `derivedStateOf`, 这条管以后新写的代码.  
  核实程度: 当场核过.

## 4. 懒布局调预取用 `LazyColumn(cacheWindow = ...)`

- `rememberLazyListState(cacheWindow = ...)` 已弃用, 配置移到 composable 上.  
  本仓库现在不带参数, 这条管以后要调预取的场合.  
  核实程度: 当场核过.

## 5. 图标跨组合复用 `ImageVector` 实例

- VectorPainter 的栅格缓存共享默认开启, 同一个 `ImageVector` 在相同尺寸下复用缓存.  
  本仓库 `AppRoot.kt:169` 用的是 `painterResource`, 已经按资源 id 缓存, 这条是以后的写法建议.  
  核实程度: 当场核过 (官方发布博客).

## 6. 退出动画用 `CapturedAnimatedVisibility`

- 退出内容依赖已经清空的状态时, 用它避免闪烁或崩溃.  
  本仓库没有 `AnimatedVisibility`, 这条管以后.  
  核实程度: 当场核过.

## 7. 多语言混排用 `LineHeightStyle.Mode.PerLine`

- 行高按行算, 防高字形文字撞行.  
  本仓库只有 zh 与 fr, 用不上.  
  核实程度: 当场核过.
