## 风险

1. 官方滚动条会改变外观.  
   自绘版照平台 View 滚动条复刻: 4dp 宽, `onSurfaceVariant` 的 52% alpha, 淡出 250ms 加 300ms 延迟 (`ScrollBarExt.kt:19-22`, `ScrollBarExt.kt:54`).  
   官方默认值不一定相同, 替换后要真机比对; 官方参数可以调, 但调不到与自绘完全一致.  
   核实程度: 当场核过 (该文件源码).
2. `clickable` 自动音效要真机确认, 尤其是无障碍与音效相关的预期.  
   `MyModelCard.kt` 的空 `onClick` 现在会出声, 而那里本来就没有动作.  
   核实程度: 当场核过.
3. `ScrollIndicatorState` 的可空性要核.  
   material3 1.5.0-alpha24 把 `ScrollIndicatorState` 参数改成了非空, 而 `ScrollBarExt.kt:40` 现在按可空处理 (`?: return this`).  
   换官方 API 时按实际签名写.  
   核实程度: 当场核过.
4. 本仓库用的 `PullToRefreshDefaults.Indicator` 是稳定的; 1.5.0 里仍标实验的是 `PullToRefreshDefaults.LoadingIndicator`, 不相干.  
   核实程度: 当场核过.
5. Robolectric 4.17 与 compileSdk 37.2 的搭配不是这次升级引入的, 但升级后单测一起看.  
   核实程度: 转述未核 (没有跑单测).
